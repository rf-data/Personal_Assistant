# Week-0-Reviewinventar, C26-CS50P-07

**HOLD.** Dieses Inventar verbindet den vorhandenen historischen Wochen-Snapshot
mit ausdrücklich getrennten Browserbeobachtungen vom 28.10.2026. Es enthält keine
heruntergeladenen Kursmaterialien, gültigen Quellenfreigaben oder behaupteten
Transcript-Erfolge.

- `evidence.json`: tatsächlich beobachtete Seiten, Titel, Angebote und Grenzen.
- `manifest.json`: hierarchische Materialobjekte, 1 Lecture, 5 Shorts, 5 Aufgaben.
- `download-plan.json`: Entwurf mit ungeprüften Quellen; kein Approval-Vertrag.
- `completeness.json`: getrennte Discovery-/Acquisition-/Manual-Bewertung, HOLD.

Ein unbekannter Short-Asset-Href bleibt `null`. Dateinamen werden nicht aus
CDN-Mustern geraten. Der Wert `manual-unresolved/...` bezeichnet einen gesperrten
Planungspfad; ein späteres echtes Exportmanifest erhält die tatsächliche,
vom bestehenden Materialvertrag abgeleitete Archividentität.

Die vollständigen Referenzlinks und Aufgabenbeschreibungen müssen später aus
echten Betreiberexporten gelesen bzw. nach Freigabe archiviert werden.
Der Builder `python -m artifacts.c26_cs50p_07.build_review_inventory` arbeitet nur
auf diesen vorhandenen Belegen und aktualisiert ausschließlich diese Reviewdateien.
Der ausführbare Discovery-/Freigabeweg steht im
[Betreiberleitfaden](../../deployment/cs50p_week_materials_operator_guide.md).
